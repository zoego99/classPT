1 AI 協作四步驟
📌 練習主題：個人綜所稅結算申報服務整合計畫
【問】釐清思路
使用時機：開始寫任何報告前，先請 AI 扮演資深幕僚向你提問，幫助你把思路整理清楚，再開始動筆。
📌 S1：Prompt — 釐清思路
協助規劃「個人綜所稅結算申報服務整合計畫」， 但我還不清楚應該聚焦哪些面向。 請先以【資深業務顧問】角色，對我提出 5 個問題，幫助我確認： 1. 這份規劃的主要受眾（所長？稅務部？客戶端？） 2. 最需要解決的服務瓶頸是什麼 3. 這次規劃要有哪些必要產出（報告、SOP、簡報？） 請一次提出所有問題，等我回答後再開始。
📌 S2：Prompt — 「結構化的定案資料」，討論匯出MD檔
我們剛才的討論已經完成，請將討論結果整理成一份 MD 檔，作為後續開新對話時的「背景資料」使用。 請依以下結構整理，禁止寫成對話紀錄或流水帳： 1. 任務背景（這份內容是做什麼、給誰看） 2. 角色設定（先前定案的AI角色，沒有則省略此項） 3. 已確認的核心重點（條列，只列我們討論中確定的內容） 4. 尚未決定／待補充的部分（如果有的話） 輸出時請放入 Markdown 程式碼區塊，方便我直接複製存檔。

目的：用於討論結束後整理結論，方便日後開新對話或免費額度用盡時，直接帶入背景接續進度。

【定】報告生成
📌 Prompt — 正式報告產出
根據我們剛才討論的內容，產出正式文件。輸出時遵守以下規範： # 角色設定 你是一位資深稅務顧問，擅長個人客戶稅務服務流程設計與申報作業規劃。 # 任務 針對「個人綜所稅結算申報服務整合計畫」進行規劃。 # 輸出格式 結構如下： ## 一、計畫背景與挑戰 ## 二、三大服務優化方向（依據我們確認的三個方向） ## 三、各部門任務分工 ## 四、關鍵 KPI 設定（僅列指標名稱與目標方向，不捏造數字） # 邊界規範 - 所有內容必須來自剛才的對話，禁止自行補充未討論的內容 - 每個章節以條列呈現，每點不超過 30 字 - 禁止捏造具體數據（KPI 僅寫「待填入」或「依實際設定」） - 部門分工表欄位：部門、任務、負責人、期限
【定】定標準三要素
定標準的三個關鍵要素：角色設定（決定語氣與專業度）、格式鎖定（指定輸出結構）、邊界聲明（明確禁止捏造數據）。
📌 Prompt — 反向查證
在你開始填充內容之前，請先做反向查證： 1. 逐一確認每個章節，是否有資料來源支撐（來自上傳文件） 2. 列出「無法從來源文件找到依據」的項目，標注 ⚠️ 3. 以上確認完成後再問我：「是否繼續生成？」
【生】反向查證角色變化版
使用時機：報告接近定稿前，模擬不同角色的挑剔視角，提前補洞。
📌 Prompt — 角色變化反向查證
例1：請扮演嚴格的所長，針對這份服務整合計畫提出 3 個可能需要改善的問題 例2：請以客戶端角度，檢查這份服務流程說明簡報是否有不容易理解的地方 例3：請以審查委員角度，指出這份成果報告可能缺少哪些數據或說明
【骨】邏輯骨架校準
📌 Prompt1 — 大綱校準
現在進入【邏輯骨架校準階段】。 請根據我們剛才完成的「個人綜所稅結算申報服務整合計畫」報告， 針對【公司總經理與各部門主管】擬定簡報大綱。 規範： - 規劃約【10】張架構 - 每頁須含主題與核心觀點，禁止跳級產出內文或旁白 - 數據頁面請標註建議採用「便當盒排版法」 - 產出後立即停止，等待進一步指令 - 強制使用 Markdown code block 區塊輸出
📌 Prompt2 — 大綱校準（對應視覺規格）
# 任務進度：【簡報大綱校準階段】 ## 銜接背景與角色設定 - **資料來源**：依據我們剛才完成的「個人綜所稅結算申報服務整合計畫」報告 - **AI 角色**：資深業務幕僚，協助將報告轉化為具說服力的簡報邏輯 - **簡報對象**：公司總經理與各部門主管，偏好數據導向、重視執行可行性 ## 簡報規格參數 - **上台時間**：15 分鐘 - **投影片張數**：約 10 張 - **輸出格式**：以「投影片 [編號]：[標題]」呈現 - **每頁必含**：核心論點摘要 + 建議視覺化圖型 ## 參、視覺與版面規格 - **整體風格**：現代數據儀表板風（淺色介面、專業 KPI 數字卡片） - **色系**：三色限定 主色：深海藍 #1E3A5F 輔色：香檳金 #C9A84C 底色：暖米白 #F5F0E8 - **視覺質感**：無陰影、無漸層、幾何平整 - **封面設計**：強制預留上方 30% 標題空白區 - **內頁排版**：複雜數據頁標註「便當盒排版法」或「網格矩陣」 ## 強制約束 - 禁止產出具體簡報文案、旁白或生圖指令 - 僅輸出邏輯骨架，產出後立即停止，等待指令 ## 格式鎖定 - 強制以 Markdown 程式碼區塊輸出大綱 「報告背景已備齊，請開始擬定簡報邏輯大綱。」

3 圖文生成技巧
資訊圖（Infographic）
📌 主題：申報前三大準備重點，少跑一趟事務所！
請生成一張【橫向 16:9】資訊圖，已包含完整排版與視覺設計。 **主視覺 / 構圖內容描述**： 畫面右側整齊並列三個圓角的便當盒格子（Bento Box），格子內分別帶有平面幾何向量感（SVG Icon）的「所得清冊」「扣除額證明」「委任書用印」插圖。畫面左側由角色「稅務顧問」手持平板進行說明，視線自然專注地望向右側的便當盒格子，形成流暢的視覺引導。 **視覺風格**： 採用「極簡向量插畫風格」風格（精準資訊視覺化）。幾何平整、線條簡潔，適合企業報告與數據說明。 - 專業穩重風（線條俐落，色調沉穩，適合金融/財稅產業） - 莫蘭迪色調（低飽和、灰調柔和，優雅沉穩） **版面配置**： 採用「便當盒排版（模組化分割）」與「左右對比」排版方式。 **文字設計細節**： - 主標題：申報前三大準備重點，少跑一趟事務所！ - 副標題：資料備齊，申報更順暢 - 重點資訊： 1. 所得清冊：先至財政部電子申報系統下載所得清單，核對是否有漏列。 2. 扣除額證明：保險費、醫療費、捐贈等單據提前整理備妥。 3. 委任書用印：委任書用印及身分證明文件請提前準備，避免臨櫃久候。 - CTA：提早準備，申報零煩惱！ **輸出規格要求**： - 比例為橫向 16:9（投影片、簡報背景圖） - 整體構圖飽滿，角色姿態與右側圖文版面具有強烈互動感，配色和諧，字體清晰易讀。
