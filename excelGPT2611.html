Step 1：讓 AI 從你的對話紀錄整理指示
💡 不用自己想要寫什麼：請 AI 先看過去的對話，整理出「你習慣怎麼問、喜歡什麼樣的回答」；用得少、還看不出習慣的地方，再由 AI 依一般人常放的方向給建議。
📌 Prompt — 請 AI 依我的對話紀錄＋一般建議，整理「Gemini 指示」
我想設定 Gemini 的「指示」，讓你之後每次回答都符合我的習慣。請先不要產出最後版本： 1. 根據你對我的記憶與過去的對話，整理你觀察到的使用習慣（例如：常問的主題、常用軟體、喜歡的回答長短與格式） 2. 依一般人常放的方向補充建議：身分與工作背景、常用軟體與版本、回答格式、語氣、不希望你做的事 3. 用表格列出：建議指示／來源（過去對話觀察 或 一般建議）／要我確認的地方 4. 一定要包含這條規則：我以【#new】開頭時，視為新問題，不沿用前一題的條件 我可以逐題回答，也可以只回覆「照建議」採用你的建議答案；等我說「開始」後，才整理成 300 字以內、可以直接貼到「Gemini 指示」的條列文字。
📍 看什麼：
  • 標示「過去對話觀察」的內容，真的是你的習慣嗎？AI 推測錯的要刪除。
  • 剛開始使用、或「記憶」沒開啟時，AI 沒有過去對話可參考，表格會幾乎都是「一般建議」，這是正常的。
  • 建議內容出現姓名、公司名稱、客戶資料等，不要放進指示。
Step 2：參考範例（Excel 學習用）
💡 Excel 的問題通常是一題一題、彼此不相關，前一題的工作表與欄位很容易被 AI 帶到下一題。所以指示裡要加一條【#new】規則：開頭打 #new，就是全新的問題。
📌 範例 — 可直接修改後貼到「Gemini 指示」
【語言與回答】 1. 一律使用台灣繁體中文與台灣常用術語。 2. 先回答重點，再補充步驟與範例。 3. 不確定的資訊請明確標示「待確認」，不要自行補充數字或事實。 【Excel 問題】 1. 我使用【Excel 2021】，Windows 11 繁體中文介面；請不要給我版本沒有的函數。 2. 給公式前，先確認：來源表、目的表、比對欄位、答案要填在哪一欄。 3. 公式附上簡短說明，並告訴我哪裡要加 $。 【新問題規則】 我以【#new】開頭時，視為新問題，不沿用前一題的工作表、欄位、公式或特殊條件。
⚠️ 指示和記憶裡不要寫個資或公司機密（身分證字號、客戶名單、實際業績）。
4. 詢問原則：口語說需求，讓 AI 反問你
情境：要寫一份完整的 Prompt 太累，常常乾脆不用 AI。
其實不用一次寫完整：先用口語把想到的說出來（手機語音輸入也可以），讓 AI 反問你、提醒你沒想到的地方，確認後再產出。
好的需求，要說清楚三件事（GPS）
GPS要說清楚什麼
G－Goal 目標我是誰？要達成什麼？
P－Position 背景資料現在的情境、手上的資料、限制
S－Shape 成果格式最後要交付的格式（Email、表格、LINE、簡報）
💡 GPS 想不完整也沒關係：口語說出來，把「整理成 G、P、S」交給 AI，缺什麼由 AI 反問。
三步驟：說 → 問 → 生
步驟你做什麼AI 做什麼
① 說用口語把想到的全部說出來，不用排順序整理成背景／目標／限制／格式
② 問逐題回答，或只回覆「照建議」反問缺少的資訊，每題附建議答案，並提醒你沒想到的地方
③ 生說「開始」產出成品；常做的工作再存成提示詞
📌 Prompt ①② — 用 AI 問 AI（萬用開頭，可存起來每次用）
我接下來會用口語講我的需求，先不要產出成品。請你： 1. 把我的話整理成：背景／目標／限制／輸出格式 2. 問我最多 5 個需要補充的問題（一次問完），每一題都直接附上你的「建議答案」 3. 提醒我「可能沒想到」的地方：容易漏掉的時間、地點、對象、格式要求 我可以逐題回答，也可以只回覆「照建議」採用你的建議答案；等我說「開始」後，才產出成品。 我的需求：【用口語說出來】
練習：口述 → 部門聚餐通知信
先貼上方 Prompt ①②，在【用口語說出來】的位置貼下方口述；AI 反問後，可以逐題回答或直接回覆「照建議」，再貼 Prompt ③。

Option Explicit Const MERGE_SOURCE_FOLDER As String = "C:\0819\1\" Const MERGE_OUTPUT_FOLDER As String = "C:\0819\" Sub MergeAllFiles() Dim fileName As String Dim wbSource As Workbook Dim wbNew As Workbook Dim wsTarget As Worksheet Dim wsSource As Worksheet Dim lastRow As Long Dim targetLastRow As Long Dim isFirst As Boolean Dim fileCount As Integer Dim outputFileName As String If Dir(MERGE_SOURCE_FOLDER, vbDirectory) = "" Then MsgBox "Folder not found: " & MERGE_SOURCE_FOLDER Exit Sub End If ' Create a brand new workbook to hold the merged result ' (does not touch this macro file or any source file) Set wbNew = Workbooks.Add Do While wbNew.Sheets.Count > 1 wbNew.Sheets(wbNew.Sheets.Count).Delete Loop Set wsTarget = wbNew.Sheets(1) Application.ScreenUpdating = False Application.DisplayAlerts = False isFirst = True fileCount = 0 fileName = Dir(MERGE_SOURCE_FOLDER & "*.xlsx") Do While fileName <> "" Set wbSource = Workbooks.Open(MERGE_SOURCE_FOLDER & fileName, ReadOnly:=True) Set wsSource = wbSource.Sheets(1) lastRow = wsSource.Cells(wsSource.Rows.Count, 1).End(xlUp).Row If isFirst Then wsSource.Rows(1).Copy wsTarget.Rows(1) isFirst = False End If If lastRow >= 2 Then targetLastRow = wsTarget.Cells(wsTarget.Rows.Count, 1).End(xlUp).Row + 1 wsSource.Rows("2:" & lastRow).Copy wsTarget.Rows(targetLastRow) End If wbSource.Close SaveChanges:=False fileCount = fileCount + 1 fileName = Dir Loop ' Save the new workbook with a timestamp to avoid overwriting previous results outputFileName = "MergedResult_" & Format(Now, "yyyymmdd_hhmmss") & ".xlsx" wbNew.SaveAs MERGE_OUTPUT_FOLDER & outputFileName, FileFormat:=51 wbNew.Close SaveChanges:=False Application.DisplayAlerts = True Application.ScreenUpdating = True MsgBox "Merge complete. Files processed: " & fileCount & vbCrLf & _ "Saved as: " & MERGE_OUTPUT_FOLDER & outputFileName End Sub

特性Google 試算表Excel（365／2021 起）
語法=FILTER(範圍, 條件1, [條件2, …])=FILTER(陣列, 條件, [若無資料])
第三個參數放「第二個條件」放「查無資料時顯示的文字」
